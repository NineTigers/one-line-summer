목표일: 7월 26일 오전

- [ ] 토스 지원 채널에 비게임 등록 가능 여부 문의
- [ ] 답변 캡처·일시·담당 채널 보존
- [ ] 한글 이름과 `appName` 후보 확인
- [ ] 고객문의 이메일·개인정보 처리방침 URL 확인

문의 문안:

> 두 사용자가 초대 링크로 참여해 토스와 스파이크 입력 타이밍을
> 조합하고 관계 결과 카드를 받는 인터랙티브 테스트입니다. 레벨,
> 랭킹, 재화, 승패, 보상, 무한 플레이가 없고 결과는 재미용으로만
> 제공합니다. 비게임 유형으로 등록 가능한지 확인 부탁드립니다.

통과 기준: 비게임 가능하다는 서면 답변 또는 콘솔에서 적용 가능한
명확한 등록 기준이 있다.

중단 기준: 게임으로만 가능하고 동일 게임의 등급분류 증빙을 마감 전
확보할 수 없다.
