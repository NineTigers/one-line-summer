# 한 줄 여름 제품 명세

- 문서 상태: v5.1 활성 기획 기준선
- 기준일: 2026-07-26 KST
- 제품 책임자: 사용자
- 앱인토스 유형: 비게임
- 현재 판정: `PASS_WITH_RISK`
- 실제 사용자 증거: 없음

## 1. 제품 결정

`한 줄 여름`은 여름 밑그림 위에 한 붓을 그리고 링크로 친구에게
토스하면, 받은 친구가 한 붓을 더해 다시 건네는 관계형 비게임
미니앱이다.

### 한 줄 소개

> 한 붓 그리고, 링크로 토스하고, 친구가 한 붓 더해요.

### 사용자 약속

> 그림을 잘 그릴 필요 없이 원하는 곳에 한 붓만 더해 친구에게
> 건넬 수 있어요.

## 2. 제품 원칙

1. **한 차례에는 한 붓만 그린다.**
2. **캔버스의 원하는 위치에서 자유롭게 시작한다.**
3. **한 붓을 저장한 뒤 다음 행동은 링크 토스 하나뿐이다.**
4. **받은 사람도 같은 규칙으로 한 붓을 더하고 다시 토스한다.**
5. **공개 피드 없이 의도한 사람에게만 링크를 건넨다.**
6. **점수·판정·완성 조건 없이 공동 창작 흔적만 남긴다.**
7. **실제 기기 공유 증거와 로컬 시뮬레이션을 구분한다.**

## 3. 핵심 흐름

### 3.1 직접 진입

첫 화면의 공개 행동은 `첫 선 그리기` 하나다. 결과 예시, 기능 소개
카드, 분기 설명은 노출하지 않는다.

### 3.2 테마 선택

사용자는 다음 여름 밑그림 중 하나를 고른다.

- 선셋 비치
- 여름 빙수집
- 한강 피크닉
- 초록 계곡
- 장마 창가
- 여름밤 불꽃
- 하얀 캔버스

밑그림은 사용자의 선보다 낮은 대비를 유지한다. 이름·장면 문장·
난이도는 입력받지 않는다.

### 3.3 한 붓 그리기

- 캔버스 어디서든 시작할 수 있다.
- 손가락을 떼기 전까지 이어진 입력을 한 붓으로 본다.
- 한 붓이 생긴 뒤에는 두 번째 붓을 추가할 수 없다.
- 저장 전 `지우고 다시`로 현재 사용자의 붓만 다시 그릴 수 있다.
- 앞사람의 선과 밑그림은 수정하거나 지울 수 없다.
- 펜 색 선택은 표현을 위한 최소 도구이며 결과를 판정하지 않는다.

### 3.4 링크로 토스

한 붓을 저장하면 현재 그림 상태를 포함한 링크를 만든다. 이 화면의
공개 행동은 `링크 복사해 토스하기` 하나다.

- 복사 성공: 친구에게 보내라는 상태만 표시한다.
- 자동 복사 실패: 직접 복사할 링크 입력창만 대체 수단으로 표시한다.
- 새 탭 열기, 이 기기에서 이어 그리기, 이력 보기, 분기 비교,
  완성하기, 재생, PNG 저장은 제공하지 않는다.

### 3.5 받은 링크

받은 사람은 지금까지의 그림을 미리 본 뒤 `바로 이어 그리기`를
누른다. 선의 이력이나 분기 수를 보여주지 않는다. 한 붓을 저장하면
새 링크를 다시 토스하는 같은 흐름으로 돌아간다.

## 4. 비게임 경계

다음 요소는 제품 전 범위에서 금지한다.

- 점수, 등급, 정확도, 성공률
- 타이머, 제한 시간, 반응속도 판정
- 승자, 패자, 순위표, 경쟁 매칭
- 재화, 보상, 출석, 확률형 결과
- 그림 실력·관계 궁합·성향의 자동 판정
- 참여 인원이나 이어진 횟수에 따른 등급 상승

한 붓 제한은 공동 창작 입력 형식이며 성공·실패나 보상 조건이 아니다.

## 5. P0와 제외 범위

### P0

- 여름 테마 선택
- 자유 시작 한 붓 입력과 다시 그리기
- 현재 그림 상태 저장
- 링크 생성·복사
- 받은 사람 미리보기와 한 붓 추가
- 익명 식별·분석·접근성·오류 처리

### 제외

- 중간 상태 선택과 이력 탐색
- 같은 시작의 분기 비교
- 로컬 기기 넘겨 그리기
- 완성 판정과 결과 화면
- 선 순서 재생과 PNG 저장
- 실시간 동시 편집
- 공개 갤러리, 좋아요, 댓글, 팔로우
- 사진·음성·위치 업로드
- AI 자동 완성
- 인앱 결제·광고·리워드

## 6. 현재 구현과 증거

`prototype/`은 URL fragment와 브라우저 `localStorage`로 그림 상태를
재현한 인터랙티브 정적 프로토타입이다.

확인할 항목:

- 390×844, 320×760 레이아웃
- 7개 여름 테마
- 자유 시작 한 붓 입력과 두 번째 붓 차단
- 링크 상태 생성과 받은 사람 화면
- 공개 흐름에 링크 토스 외 보조 기능이 없는지
- reduced motion과 브라우저 콘솔 오류·경고

아직 증명하지 못한 항목:

- 서로 다른 실제 기기와 사용자 사이의 데이터 동기화
- Apps in Toss 공유·익명 식별·딥링크
- Supabase 보안·동시성·만료
- 실제 사용자가 한 붓을 더하고 다시 토스하는지

따라서 프로토타입은 상호작용 증거이지 출시 가능한 백엔드 증거가
아니다.

## 7. 출시 게이트

1. Apps in Toss 두 실기기에서 생성 → 공유 → 이어 그리기가 된다.
2. 다섯 그룹 중 네 그룹이 설명 없이 첫 붓과 이어 그리기를 완료한다.
3. 다섯 그룹 중 세 그룹이 실제로 다음 사람에게 링크를 재토스한다.
4. 링크 취소·복사 실패·만료 상태에서도 막힌 화면이 생기지 않는다.
5. 비게임 검수 문구와 실제 기능에 점수·판정·보상이 없다.

게이트 전에는 “재미가 검증됐다”거나 “우승 가능성이 높다”고
확정하지 않는다.
