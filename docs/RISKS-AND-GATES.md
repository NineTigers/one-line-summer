## 2. 비게임 검수 게이트

출품 전 코드·문구·분석에서 다음이 모두 없어야 한다.

- 점수, 등급, 정확도, 성공·실패 판정
- 타이머, 제한 시간, 반응속도 측정
- 승자, 패자, 순위, 대전
- 재화, 보상, 출석, 확률형 결과
- 참여 인원·분기 수의 등급화
- 그림이나 관계의 자동 평가

`끝점에서 시작`과 `한 번에 한 획`은 공동 문서 편집 규칙으로만
설명한다. 사용자에게 미스·실패를 부여하지 않는다.

## 4. 중단 기준

- 두 기기에서 동일 부모 분기가 안정적으로 보존되지 않는다.
- 5그룹 중 3그룹 이상이 중간 분기를 이해하지 못한다.
- 받은 링크가 관계상 부담스럽다는 반응이 반복된다.
- 실제 사용자 대부분이 `그냥 메신저로 그림 보내면 된다`고 평가한다.
- 마감 전 G2·G3를 완료할 시간이 없어 정적 시연만 남는다.

중단 시 기존 자산과 문서는 보존하되 출시·출품 완료로 보고하지
않는다.
