중복이면 `summer-one-line` → `one-line-summer-draw` 순으로 시도한다.

## 2. 부제

> 한 붓 그리고, 링크로 토스하고, 친구가 한 붓 더해요.

대안:

> 친구와 한 붓씩 주고받는 여름 그림

## 3. 상세 설명

```
여름 밑그림 위에 한 붓만 그리고, 링크로 친구에게 건네요.
받은 친구가 한 붓을 더해 다시 건네면 우리 여름 그림이 됩니다.

- 여름 배경 7종 중 하나를 고릅니다.
- 캔버스 어디서든 시작해 한 붓을 그립니다.
- 저장하면 그림이 담긴 링크가 만들어집니다.
- 링크를 받은 친구가 한 붓을 더해 다시 토스합니다.

한 사람은 한 차례에 이어진 선 하나만 더할 수 있어요.
앞사람의 선은 지울 수 없습니다.

잘 그릴 필요가 없습니다. 점수도, 시간 제한도, 순위도 없습니다.
```

## 4. 비게임 근거

검수에서 게임으로 오인될 여지를 미리 없앤다. 필요하면 이 문단을
그대로 제출한다.

```
이 앱에는 점수, 등급, 정확도, 성공·실패 판정이 없습니다.
타이머와 제한 시간이 없고, 승자·패자·순위표·대전이 없습니다.
재화, 보상, 출석, 확률형 결과가 없습니다.
그림 실력이나 관계를 자동으로 평가하지 않습니다.

'한 차례에 한 붓'은 여러 사람이 한 그림을 함께 그리기 위한
공동 편집 규칙이며, 성공 조건이나 보상 조건이 아닙니다.
```

## 9. 심사 설명에 쓸 증거 구분

과장하지 않기 위해 다음을 구분해 적는다.

- **확인됨**: 브라우저에서 배경 선택 → 한 붓 → 링크 생성 → 받은 링크로
  이어 그리기. 링크 인코딩 왕복과 길이 상한은 자동 테스트로 확인.
- **미확인**: 토스 실기기에서의 익명 키 발급, 딥링크 진입, 네이티브
  공유. 두 기기 왕복. 실제 사용자 플레이테스트.

실기기 증거가 생기기 전에는 `실기기에서 동작 확인` 이라고 쓰지
않는다.
