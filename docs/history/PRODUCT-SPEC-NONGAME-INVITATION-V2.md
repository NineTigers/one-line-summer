# 올여름 내가 토스할게 제품 명세

- 문서 상태: 비게임 전환 구체안·사용자 확인 대기
- 버전: v2
- 기준일: 2026-07-26 KST
- 제품 책임자: 사용자
- 이전 버전: `docs/history/PRODUCT-SPEC-GAME-V1.md`

## 1. 제품 정의

`올여름 내가 토스할게`는 여름에 함께하고 싶은 한 사람에게
`내가 먼저 맡을 일`과 `함께 보고 싶은 장면`을 웹툰 한 컷으로
건네고, 상대가 자신의 약속을 보태 둘만의 여름 초대장을 완성하는
관계형 커뮤니케이션 미니앱이다.

비치발리볼은 조작 대상이나 경기 규칙이 아니라 `먼저 공을 건네고
상대가 이어준다`는 관계의 시각적 은유로만 사용한다.

### 한 줄 소개

> 내가 맡을 한 가지를 먼저 토스하고, 상대가 한 가지를 보태
> 둘만의 여름 한 컷을 완성해요.

### 사용자 약속

> 오랜만에 말을 걸고 싶은 사람에게 부담 없는 여름 장면과 작은
> 약속을 먼저 건네고, 상대의 답을 받아 실제로 공유할 초대장을
> 만든다.

## 2. 비게임 경계

다음 기준은 출시 전까지 기능·카피·분석 이벤트에 동일하게 적용한다.

| 유지하는 것 | 제거하는 것 |
| --- | --- |
| 여름 해변과 비치발리볼 웹툰 | 실시간 타이밍 입력 |
| 공을 건넨다는 `토스` 언어유희 | 공 궤적을 맞히는 조작 |
| 두 사람이 한 번씩 내용을 보탬 | 정답·오답·성공·실패 |
| 장면·역할·문구의 명시적 선택 | 점수·등급·정타·미스 |
| 자동으로 재생되는 장면 전환 | 라운드·스테이지·승패 |
| 완성된 초대장 저장·공유 | 개인 최고 기록·재도전 |

모든 선택에는 정답이나 우열이 없다. 선택 결과는 숨은 알고리즘이나
궁합 판정 없이 사용자가 고른 내용 그대로 최종 카드에 표시한다.

## 3. 핵심 흐름

### 3.1 프롤로그

- 두 사람의 표시 이름을 입력한다.
- `같은 기기로 체험하기` 또는 정식 버전의 `초대장 만들기`를 누른다.
- 첫 화면은 기존 표지 이미지를 유지하되 `플레이` 대신
  `여름 웹툰 초대장`으로 설명한다.

### 3.2 첫 번째 사람 — 장면을 토스하기

첫 사람이 이번 여름에 함께 남기고 싶은 장면 하나를 고른다.

- `파도에 뛰어들기` — 한낮의 바다
- `노을까지 머물기` — 해 질 무렵
- `여름밤 천천히 걷기` — 바람 부는 밤

이어서 자신이 먼저 맡을 일 하나를 고른다.

- 장소 찾기
- 시간 맞추기
- 준비물 챙기기
- 시원한 간식 맡기

선택형 말풍선 하나를 덧붙인다.

- `이번 여름은 내가 먼저 말 걸게.`
- `일단 날짜부터 같이 비워볼래?`
- `거창하지 않아도 같이 한 장면 남기자.`

`이 장면 토스하기`를 누르면 공이 화면을 가로지르는 짧은 자동
전환이 재생된다. 누르는 시점이나 속도는 결과에 영향을 주지 않는다.

### 3.3 두 번째 사람 — 답을 보태기

두 번째 사람은 첫 사람이 고른 장면과 약속을 그대로 확인한다.
그 뒤 자신의 응답 하나를 고른다.

- `좋아, 같이 가자.`
- `천천히 날짜부터 맞춰보자.`
- `이번에는 내가 이어갈게.`

그리고 자신이 보탤 일 하나를 고른다.

- 사진 남기기
- 길 찾기
- 여름 음악 고르기
- 현장 분위기 맡기

`내 약속 보태기`를 누르면 두 사람의 선택이 합쳐진다. 응답은 첫
사람의 선택을 평가하거나 수정하지 않는다.

### 3.4 에필로그 — 우리의 여름 한 컷

최종 화면은 점수나 관계 유형 대신 다음 사실만 보여준다.

- 두 사람의 이름
- 함께 고른 여름 장면
- 첫 사람이 맡은 일과 말풍선
- 두 번째 사람이 보탠 일과 응답
- `우리의 2026 여름 한 컷` 스탬프

예시:

> 나 × 친구의 2026 여름 한 컷
>
> 노을까지 머물기
>
> 나는 장소를 찾고, 친구는 사진을 남기기로 했어요.
>
> “천천히 날짜부터 맞춰보자.”

주요 CTA는 `이 한 컷 공유하기`다. 보조 CTA는 `다른 장면 만들기`로
표현하며 점수 향상이나 재도전의 의미를 주지 않는다.

## 4. 시각·상호작용 방향

시각 방향 `여름 스포츠 웹툰 × 로맨틱 코미디 × 한 장의 초대장`은
유지한다.

| 자산 | 새 역할 |
| --- | --- |
| `comic-cover.jpg` | 프롤로그 표지 |
| `comic-toss.jpg` | 첫 사람의 장면·약속 선택 배경 |
| `comic-spike.jpg` | 상대가 초대를 받고 답을 보태는 장면 |
| `comic-finale.jpg` | 완성된 여름 초대장 |

동적 공은 사용자가 조작하는 대상이 아니라 페이지 전환을 연결하는
장식이다. 반복 이동, 대기 타이밍, 접점 효과, 속도선 판정은 제거한다.
`prefers-reduced-motion`에서는 공 이동 없이 장면이 교체된다.

웹툰 문법은 다음 요소로 유지한다.

- 프롤로그·첫 번째 컷·답장 컷·에필로그의 장 구성
- 선택한 문장이 실제 말풍선에 반영되는 연출
- 한낮·노을·여름밤 색감
- 최종 포스터와 2026 여름 기록 스탬프

## 5. 비목표

- 실시간 조작과 반응속도 측정
- 성공·실패·정확도·점수·궁합도
- 캐릭터 능력, 라운드, 레벨, 스테이지
- 재화, 보상, 리더보드, 확률 요소
- 과학적 성향·관계·심리 판정
- 연인 전용 표현
- 연락처 불러오기와 정확한 위치 수집
- 사용자의 선택과 무관한 결과 생성

## 6. 앱인토스 활용

정식 버전에서 필요한 기능은 비게임 서비스 흐름에 한정한다.

- 익명 사용자 식별
- 초대 링크 또는 공유 기능
- 링크 상태에 따른 첫 사람·두 번째 사람 화면 분기
- 완성 카드 공유
- 필요할 경우 저장한 초대장 다시 보기

결제, 광고, 리워드, 게임 사용자 키, 리더보드는 사용하지 않는다.

## 7. 안전 통과 기준

다음 중 하나라도 생기면 비게임 경계를 다시 검토한다.

- 누르는 시점·속도·정확도를 저장하거나 비교함
- 선택을 잘함·못함으로 평가함
- 점수, 등급, 적중, 실패, 승패를 표시함
- 반복 수행으로 더 좋은 결과를 얻도록 유도함
- 숨은 계산으로 궁합이나 유형을 판정함

출시 후보에는 아래 조건을 모두 만족해야 한다.

- 사용자의 선택이 최종 카드에 그대로 보인다.
- 모든 선택은 제출 전 자유롭게 수정할 수 있다.
- 상대의 응답이 없더라도 첫 초대장을 공유할 수 있다.
- 낮은 선택이나 불리한 결과가 존재하지 않는다.
- 320px와 390px에서 선택·확인·공유 CTA가 가려지지 않는다.
- 모션 없이도 모든 의미와 진행 상태를 이해할 수 있다.
- 화면 낭독기에서 선택 그룹과 선택 상태를 확인할 수 있다.

## 9. 검증

### 현재 증거

- 소스 확인: 완료
- 기존 이미지 정적 확인: 완료
- 현재 인터랙티브 기준 화면: 브라우저 정책 제한으로 미확인
- 새 흐름 구현: 미착수
- 사용자 플레이테스트: 미실시

### 저비용 확인 질문

1. 설명 없이 `상대에게 여름 초대장을 만드는 서비스`로 이해하는가?
2. 점수나 정답을 기대하는가?
3. 첫 사람이 맡을 일과 상대가 보탠 일이 최종 카드에서 명확한가?
4. 실제 친구·가족·연인 중 한 사람에게 보내고 싶은가?
5. 결과가 관계를 평가한다고 느끼는가?

### 성공 조건

- 5명 중 4명 이상이 게임·테스트가 아니라 초대장 또는 약속 만들기로 설명
- 5명 중 4명 이상이 점수나 정답을 기대하지 않음
- 5명 중 3명 이상이 실제 전송 의향을 표시
- 첫 초대장 완성 중앙값 45초 이하

### 중단 조건

- 두 명 이상이 타이밍 게임이나 궁합 테스트로 오해함
- 선택 카드가 재미용 결과 뽑기로 인식됨
- 실제 전송 의향이 두 명 이하
- 공유 전 과정이 90초를 넘김
