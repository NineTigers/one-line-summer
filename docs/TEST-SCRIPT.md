# 한 줄 여름 V5.2 체험 점검표

대상: `index.html` · `src/`

```bash
npm install && npm run dev
```

`http://localhost:5173/`에서 연다.

## 1. 최소 흐름

- [ ] 첫 화면의 본문 CTA는 `첫 한 붓 그리기` 하나뿐이다.
- [ ] 결과 예시·기능 카드·분기·이력·완성 설명이 없다.
- [ ] `첫 한 붓 그리기` 뒤 테마 선택으로 바로 이동한다.
- [ ] 한 붓을 저장하고 공유하는 CTA는 `친구에게 토스하기` 하나다.
- [ ] 공유 전에 별도의 한 붓 확인·전달 화면을 거치지 않는다.
- [ ] 같은 기기에서 이어 그리기·중간 선 선택·완성·재생·PNG 저장·
  새 탭 열기 기능이 없다.
- [ ] 점수·승패·시간 제한·보상 문구가 없다.

## 2. 테마와 한 붓

- [ ] 선셋 비치·여름 빙수집·한강 피크닉·초록 계곡·장마 창가·
  여름밤 불꽃·하얀 캔버스가 선택된다.
- [ ] 선택한 밑그림이 Canvas와 다음 화면 미리보기에 동일하게 남는다.
- [ ] 밑그림은 사용자 펜 선보다 낮은 대비로 보인다.
- [ ] 별도 이름·장면 입력 없이 테마 선택 뒤 바로 그릴 수 있다.
- [ ] 펜 색 4종을 44px 이상 터치 버튼으로 고를 수 있다.
- [ ] 별도 시작점·끝점 표시가 없다.
- [ ] Canvas 어느 위치에서든 첫 터치 위치부터 선이 그려진다.
- [ ] 손가락을 떼면 한 붓이 끝나고 두 번째 붓은 추가되지 않는다.
- [ ] 저장 전 `다시 그리기`로 현재 붓만 다시 그릴 수 있다.
- [ ] 유효한 붓 전에는 `친구에게 토스하기`가 비활성이다.
- [ ] 펜 색 버튼의 접근 가능한 이름이 실제 색 이름으로 제공된다.

## 3. 링크 토스

- [ ] `친구에게 토스하기` 한 번으로 한 붓 저장과 공유가 함께 실행된다.
- [ ] 브라우저 공유 기능이 있으면 시스템 공유 창을 바로 연다.
- [ ] 브라우저 공유 기능이 없으면 현재 그림 URL을 복사한다.
- [ ] 공유와 복사가 모두 실패할 때만 직접 복사용 링크를 보여준다.
- [ ] 공유 뒤 캔버스와 색상·다시 그리기가 잠기고, 같은 링크만 다시
  공유할 수 있다.
- [ ] 공유 URL을 열면 지금까지의 그림과 `한 붓 더하기`만 보인다.
- [ ] 받은 화면에 선 이력·분기 수·결과 비교 버튼이 없다.
- [ ] 새 참여자도 원하는 위치에 한 붓만 더할 수 있다.
- [ ] 새 붓 저장 후 URL이 새 그림 상태로 바뀌고 다시 토스할 수 있다.

## 4. 접근성·모션

- [ ] 주요 버튼·테마 라디오·펜 색 버튼이 접근 가능한 이름을 가진다.
- [ ] Canvas에는 텍스트 대체 이름과 별도 상태 메시지가 있다.
- [ ] 키보드 초점이 보인다.
- [ ] `?motion=reduce`에서 반복 펄스와 부드러운 스크롤이 억제된다.

## 5. 레이아웃

- [ ] 360×740에서 받은 그림과 `한 붓 더하기` CTA가 한 화면에 보인다.
- [ ] 320×760에서 홈 제목·CTA가 잘리지 않는다.
- [ ] 320×760에서 테마 카드가 한 화면 폭 안에 있다.
- [ ] 테마 선택 CTA가 화면 아래에 고정되고 선택한 테마명을 보여준다.
- [ ] 320×760에서 제목·Canvas·펜 색·두 그리기 버튼이 순서대로
  보이고 가로 스크롤이 없다.
- [ ] 화면 전환 뒤 내부 스크롤이 0으로 돌아간다.
- [ ] 최소 터치 영역이 44px다.

## 7. 토스 번들과 딥링크

```bash
npx ait build
```

- [ ] `one-line-summer.ait`가 만들어진다.
- [ ] 번들이 압축 해제 기준 100MB 이하다.
- [ ] `dist/web/`에 밑그림 6장이 모두 들어간다.
- [ ] `?d=<토큰>`으로 열어도 `#d=<토큰>`과 같은 그림이 열린다.
- [ ] 모든 화면에서 뒤로가기가 앞 화면으로 가고 앱을 종료하지 않는다.
- [ ] 브릿지가 없는 브라우저에서 공유가 조용히 클립보드로 넘어간다.

실기기에서만 확인되는 것 (아직 못 함):

- [ ] 받은 사람 기기에서 딥링크가 앱을 열고 그림이 이어진다.
