# 한 줄 여름 플레이테스트 계획

- 문서 상태: v5 활성
- 목적: 사용자가 설명 없이 한 획·중간 공유·분기 비교를 이해하고,
  그 차이를 실제 재미로 느끼는지 확인
- 현재 `player_evidence_status`: missing

## 1. 검증할 가설

### H1 · 한 획은 부담을 낮춘다

빈 캔버스보다 끝점과 한 획 제한이 시작 결정을 쉽게 만든다.

### H2 · 예상 밖의 해석이 감정 사건을 만든다

다음 사람이 내 선을 다르게 이어 완성 그림이 예상에서 벗어날 때
웃음·놀람·대화가 생긴다.

### H3 · 중간 분기가 차별점이다

같은 완성 그림을 한 번 공유하는 것보다, 같은 중간 선을 여러
사람에게 보내 서로 다른 결과를 비교하는 행동이 더 기억된다.

### H4 · 비게임 경계에서도 다시 할 이유가 있다

점수·보상·승패가 없어도 다른 사람에게 같은 시작을 보내 새 결과를
보고 싶어진다.

## 2. 참가자

- 5개 그룹, 그룹당 2~4명
- 친구·가족·연인·동료 관계를 섞는다.
- 그림을 즐기는 사람과 부담스러워하는 사람을 모두 포함한다.
- 제작자가 옆에서 설명하지 않는 원격 링크 테스트를 최소 3그룹에
  포함한다.

## 3. 테스트 순서

### A. 10초 이해

첫 화면만 보여주고 질문한다.

- 무엇을 하는 앱 같나요?
- 다음에 무엇을 누를 것 같나요?
- 여러 갈래는 무엇을 뜻한다고 생각하나요?

### B. 첫 획

참가자 A에게 별도 설명 없이 첫 선을 만들게 한다.

관찰:

- 시작점에서 5초 이상 멈추는가
- 끝점이 아닌 곳에서 시작했다가 복구 가능한가
- 제출 전에 다시 그리기를 발견하는가
- 그림을 잘 그려야 한다는 부담을 말하는가

### C. 받은 획

참가자 B가 다른 기기에서 링크를 연다.

관찰:

- 앞의 선과 자신의 차례를 구분하는가
- 빛나는 끝점에서 자연스럽게 시작하는가
- 한 획 뒤 무엇이 저장됐는지 이해하는가

### D. 같은 중간 선 분기

A가 첫 획 링크를 B와 C에게 동시에 보낸다. 두 사람은 서로 보지
않고 한 획을 추가한다. A는 원본 흐름에서 두 결과를 비교한다.

질문:

- 두 그림이 같은 시작이었다는 것이 보이나요?
- 어느 부분이 예상과 달랐나요?
- 다른 사람에게도 같은 시작을 보내고 싶나요? 왜인가요?

### E. 네 획 완성

A와 B가 두 번씩 번갈아 네 획을 만든다.

관찰:

- 역할 교대를 이해하는가
- 완성 시점을 자연스럽게 받아들이는가
- 순서 재생이 관계의 흔적을 설명하는가
- PNG 저장보다 중간 분기를 먼저 선택하는가

## 4. 기록 항목

### 행동

- 첫 CTA까지 시간
- 유효 첫 획까지 시간
- 잘못된 시작점 횟수
- 수신 획 완료 여부
- 중간 선 다중 공유 여부
- 실제 형제 가지 수
- 분기 비교 열람 여부
- 네 획 완성 여부

### 발화

- 웃음·놀람·당황이 발생한 정확한 순간
- `내 선이 이렇게 될 줄 몰랐다`와 유사한 자발 발화
- 그림 실력 평가로 느꼈는지
- 받은 링크가 부담 또는 스팸으로 느껴졌는지
- 기존 메신저 그림 이어그리기와 다른 점

## 5. 판정

### PASS

- 5그룹 중 4그룹 이상이 무설명으로 첫 획·수신 획 완료
- 3그룹 이상이 같은 중간 선을 두 사람 이상에게 전송
- 3그룹 이상이 분기 차이를 자발적으로 설명
- 치명적 데이터 덮어쓰기 0건

### PASS_WITH_RISK

- 핵심 분기는 이해하지만 첫 화면이나 끝점 입력 마찰이 반복됨
- 공유 의향은 있으나 실제 두 번째 수신이 부족함

### REWORK

- 사용자가 완성 그림 공유만 이해하고 중간 분기를 발견하지 못함
- 한 획 제한이 자유를 빼앗는 규칙으로만 느껴짐

### STOP

- 실제 공유가 대부분 부담으로 인식됨
- 분기 비교가 새로움이나 대화를 만들지 못함
- 메신저에서 사진을 주고받는 것보다 명확한 가치가 없음
