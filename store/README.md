## V5 스크린샷 서사

1. `끝점에서 한 획` — 받은 선과 빛나는 다음 끝점
2. `같은 시작, 다른 결과` — 한 부모에서 갈라진 두 그림
3. `우리 선의 순서` — 네 획 완성과 재생·중간 분기 CTA

세 장만 보고도 단순 그림 앱이 아니라 `중간 상태를 여러 사람에게
보내 결과가 갈라지는 제품`임을 이해해야 한다.

## 썸네일 방향

- 한 개의 시작점과 공통 첫 선
- 중앙에서 두 갈래로 갈라진 서로 다른 완성
- 문구 후보: `같은 선, 다른 여름`
- 작은 지면에서 읽히지 않는 참여자 이름·세부 UI는 제외
- 게임 점수판·대전·승패로 오인될 배지는 사용하지 않음

## 제작 게이트

다음 항목 전에는 최종 자산을 만들지 않는다.

- Supabase 실제 분기 저장
- Apps in Toss 두 실기기 왕복
- 5그룹 사용자 테스트에서 중간 분기 가치 확인
- V5 공개 이름과 `appName` 확정

게이트를 통과한 실제 앱 화면으로 다시 캡처하고, 렌더링용 분기를
제품 코드에 남기지 않는다.
