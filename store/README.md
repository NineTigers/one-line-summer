## 스크린샷 재생성 방법

프로토타입 사본에 렌더링용 스크립트를 붙여 헤드리스 크롬으로 찍는다.
제품 코드에는 스크린샷용 분기를 넣지 않는다.

1. `prototype/`을 임시 폴더로 복사한다.
2. 사본에 `html { zoom: 3; }` 스타일과, 쿼리 `?shot=1|2|3`에 따라
   화면을 구성하는 스크립트를 추가한다.
3. `python3 -m http.server`로 사본을 띄운다.
4. 헤드리스 크롬으로 `--window-size=1170,2532 --virtual-time-budget=4000`
   옵션을 주고 `--screenshot`으로 저장한다.

`--force-device-scale-factor`는 레이아웃 뷰포트가 어긋나 오른쪽이
잘리므로 쓰지 않는다. `scrollIntoView`도 zoom과 충돌하므로 스크롤
대신 표시할 컷 수를 조절해 원하는 영역을 화면에 담는다.

## V3 스크린샷 순서 의도

컷 만들기 → 이어진 릴레이 → 완성 포스터 순서로 배열해, 설명 없이도
`혼자 만드는 게 아니라 이어지는 것`이라는 구조가 읽히게 한다.
