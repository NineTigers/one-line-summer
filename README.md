# 올여름 내가 토스할게

여름 한 컷을 만들어 친구에게 토스하면, 친구가 자기 컷을 보태
다음 사람에게 넘기며 이어지는 비게임 관계형 미니앱이다.

## 프로젝트 상태

| 항목 | 현재 결정 |
| --- | --- |
| 공개 이름 | `올여름 내가 토스할게` |
| 대표 문구 | `올여름, 내가 토스할게!` |
| 제품 유형 | 비게임 관계형 미니앱 · 여름 토스 릴레이 |
| 앱인토스 유형 | 공식 확인 전 미확정 |
| `appName` | 콘솔 중복 확인 전 미확정 |
| 공모전 | 2026년 7월 앱인토스 바이브코딩 챌린지 |
| 우선순위 | 출품 포트폴리오 2순위·조건부 |
| 저장소 역할 | 전용 코드·기획·실험·출품 증빙 |

## 한 문장 약속

> 내가 여름 한 컷을 먼저 토스하면, 친구가 이어받아 우리 여름이
> 한 장씩 길어져요.

## 핵심 원칙

- 토스는 `다음 사람에게 넘기는 행동`이다. 조작 대상이 아니라
  관계를 잇는 은유이자 실제 전달 동작이다.
- 점수·타이밍·승패·정확도·순위를 두지 않는다. 게임물 분류를
  피하기 위한 선택이자 제품 정체성이다.
- 참여 인원 표시는 사실이지 성취가 아니다. 보상이나 비교로
  이어지지 않는다.
- 레벨·랭킹·재화·광고·리워드·과학적 궁합 주장을 두지 않는다.
- 공식 앱 유형 확인 전 출품용 앱 등록을 확정하지 않는다.
- 다른 출품 앱과 코드·사용자 데이터·배포를 공유하지 않는다.
- Codex 앱 자동화 기능은 사용하지 않는다.

## 브라우저 체험판

`prototype/`에는 링크로 이어지는 여름 토스 릴레이 구현이 있다.
백엔드 없이 릴레이 상태를 링크에 담으므로 서버·DB·개인정보 저장이
없다. 한낮·노을·여름밤 배경과 웹툰 말풍선으로 컷을 구성한다.

```bash
python3 -m http.server 4184 --directory prototype
```

실행 후 `http://127.0.0.1:4184`에서 열고
[체험 점검표](prototype/TEST-SCRIPT.md)를 따른다.
