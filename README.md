# 한 줄 여름

친구가 남긴 연속선의 끝에서 한 획을 이어 공동 그림을 만들고, 어느
중간 선이든 여러 사람에게 다시 보내 서로 다른 여름으로 갈라지게
하는 관계형 비게임 미니앱이다.

## 한 문장 약속

> 같은 선에서 시작해도 우리마다 다른 여름.

## 핵심 원칙

- 한 사람은 한 번에 연속선 한 획만 보탠다.
- 새 선은 앞사람이 남긴 끝점에서 시작한다.
- 모든 중간 상태는 다시 공유할 수 있다.
- 같은 상태를 여러 사람이 받으면 서로 다른 자식 가지가 생긴다.
- 비교 화면은 차이를 보여줄 뿐 정답·승자·순위를 만들지 않는다.
- 점수·타이머·성공률·보상·관계 판정은 두지 않는다.
- 공개 피드, 정확한 위치, 연락처, 사진은 P0에서 수집하지 않는다.
- 다른 출품 앱과 코드·사용자 데이터·배포를 공유하지 않는다.
- Codex 앱 자동화 기능은 사용하지 않는다.

## 현재 브라우저 체험판

```bash
python3 -m http.server 4184 --bind 127.0.0.1 --directory prototype
```

실행 후 `http://127.0.0.1:4184/`에서 다음 흐름을 확인한다.

1. 첫 선 만들기
2. 끝점에서 한 획 잇기
3. 현재 또는 중간 선 공유
4. 같은 중간 선의 여러 결과 비교
5. 네 획 완성·순서 재생·PNG 저장

`prototype/`의 링크 데이터와 분기 목록은 URL fragment와 같은
브라우저의 `localStorage`를 쓰는 검증용 구현이다. 다른 사람의
기기에서 실제로 이어지는 출시 버전은 Supabase와 Apps in Toss
딥링크 연동이 필요하다.
