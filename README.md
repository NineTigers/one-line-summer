# 올여름 내가 토스할게

토스와 스파이크를 서로 한 번씩 주고받아 두 사람의 여름 호흡을
확인하는 비동기 소셜 타이밍 테스트다.

## 프로젝트 상태

| 항목 | 현재 결정 |
| --- | --- |
| 공개 이름 | `올여름 내가 토스할게` |
| 대표 문구 | `올여름, 내가 토스할게!` |
| 제품 유형 | 소셜 타이밍 테스트 |
| 앱인토스 유형 | 공식 확인 전 미확정 |
| `appName` | 콘솔 중복 확인 전 미확정 |
| 공모전 | 2026년 7월 앱인토스 바이브코딩 챌린지 |
| 우선순위 | 출품 포트폴리오 2순위·조건부 |
| 저장소 역할 | 전용 코드·기획·실험·출품 증빙 |

## 한 문장 약속

> 내 리듬을 먼저 건네고 서로 한 번씩 받아주며, 둘만의 2026 여름
> 호흡을 확인해요.

## 핵심 원칙

- 토스는 `먼저 리듬을 건네는 행동`, 스파이크는 `상대 리듬을 읽고
  완성하는 행동`이다.
- 한쪽만 상대에게 맞추지 않도록 반드시 역할을 바꾼다.
- 결과는 관계의 진실이 아니라 `오늘의 호흡`을 재미로 표현한다.
- 레벨·랭킹·재화·광고·승패·과학적 궁합 주장을 두지 않는다.
- 공식 앱 유형 확인 전 출품용 앱 등록을 확정하지 않는다.
- 다른 출품 앱과 코드·사용자 데이터·배포를 공유하지 않는다.
- Codex 앱 자동화 기능은 사용하지 않는다.

## 브라우저 체험판

`prototype/`에는 같은 기기를 두 사람이 주고받는 토스–스파이크
패스앤플레이 체험판이 있다.

```bash
python3 -m http.server 4174 --directory prototype
```

실행 후 `http://127.0.0.1:4174`에서 열고
[체험 점검표](prototype/TEST-SCRIPT.md)를 따른다.
