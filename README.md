# 올여름 내가 토스할게

두 개의 여름 장면과 가능한 날짜를 한 사람에게 토스하면, 상대가
하나를 선택하고 역할을 보태 실제 약속을 완성하는 1:1 비게임
미니앱이다.

## 한 문장 약속

> 두 개의 여름을 토스하면, 친구가 하나를 받아 우리 약속을 완성해요.

## 핵심 원칙

- 두 선택지, 날짜 2~3개, 각자의 역할로 실제 약속을 확정한다.
- 보내는 사람과 받는 사람은 서로 다른 화면과 행동을 가진다.
- 상대의 답은 서버 상태를 바꾸며 원본 화면에서도 최신 상태가 보인다.
- 점수·타이밍·승패·정확도·순위·보상은 두지 않는다.
- 실명·전화번호·연락처·정확한 위치는 수집하지 않는다.
- 릴레이 길이나 억지 출석이 아니라 답장과 확정 약속이 재방문 이유다.
- 다른 출품 앱과 코드·사용자 데이터·배포를 공유하지 않는다.
- Codex 앱 자동화 기능은 사용하지 않는다.

## 현재 브라우저 체험판

`prototype/`은 대체된 V3 릴레이의 비교 기준이다. 활성 V4 제품으로
오인하지 않는다.

```bash
python3 -m http.server 4184 --directory prototype
```

실행 후 `http://127.0.0.1:4184`에서 기존 흐름을 확인할 수 있다.
