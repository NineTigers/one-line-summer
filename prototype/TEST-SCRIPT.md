# 여름 토스 릴레이 체험 점검표

> 상태: 대체된 V3 릴레이 비교 기준. 활성 V4 제품 검증에는
> `docs/PLAYTEST-PLAN.md`를 사용한다.

대상: `prototype/` (v3 릴레이 구현)
역사 기준 문서: `docs/CONCEPT-V3-SUMMER-RELAY.md`

```bash
python3 -m http.server 4184 --directory prototype
```

`http://127.0.0.1:4184`에서 연다.

## 1. 첫 진입 (마찰 점검)

- [ ] 프롤로그·표지·튜토리얼 없이 곧바로 `여름 장면` 선택지가 보인다
- [ ] 이름 입력을 요구하지 않는다
- [ ] 첫 화면에서 첫 탭까지 1초를 넘기지 않는다

## 2. 컷 만들기

- [ ] 장면 3종이 각각 다른 배경 이미지로 보인다
- [ ] 장면과 역할을 고르기 전에는 `토스하기`가 비활성이다
- [ ] 둘 다 고르면 활성화되고 안내가 `시간 제한은 없어요`로 바뀐다
- [ ] 한마디는 선택형과 직접 입력 둘 다 된다. 직접 입력이 우선한다
- [ ] 이름을 비우면 `여름 친구`로 표기된다
- [ ] 선택은 제출 전 몇 번이든 바꿀 수 있다

## 3. 토스 전환

- [ ] 공이 화면을 가로지르는 전환이 1회 재생된다
- [ ] 누르는 시점·속도에 따라 결과가 달라지지 않는다
- [ ] 판정, 점수, 성공·실패 문구가 어디에도 없다

## 4. 릴레이 화면

- [ ] `올여름이 N일 남았어요` 카운트다운이 보인다
- [ ] 내 컷이 스트립에 표시된다
- [ ] 포스터에 `우리 N명의 2026 여름`과 참여자 이름이 보인다
- [ ] 공유 링크가 만들어진다

## 5. 링크 왕복 (핵심)

- [ ] 공유 링크를 새 탭에서 열면 `여름 한 컷이 도착했어요`가 뜬다
- [ ] 앞사람의 컷이 그대로 보인다
- [ ] `나도 이어쓰기`로 내 컷을 보탤 수 있다
- [ ] 스트립에 두 컷이 공 커넥터로 이어져 보인다
- [ ] 포스터가 `우리 2명의 2026 여름`으로 갱신된다
- [ ] 3명 이상으로 이어도 순서대로 쌓인다

## 6. 접근성

- [ ] 화면 낭독기에서 `여름 장면`, `내가 맡을 것`, `한마디` 그룹이 읽힌다
- [ ] 각 선택지가 값이 아니라 문구로 읽힌다
- [ ] 키보드 Tab과 화살표로 선택할 수 있고 초점 테두리가 보인다
- [ ] `?motion=reduce`에서 공 전환 없이 곧바로 릴레이 화면으로 간다

## 7. 레이아웃

- [ ] 320px에서 가로 스크롤이 생기지 않는다
- [ ] 390px에서 모든 CTA가 가려지지 않는다

## 8. 비게임 경계 (출품 전 필수)

- [ ] 점수·등급·정확도·정타·미스 표기가 없다
- [ ] 승패, 성공, 실패, 재도전 유도가 없다
- [ ] 타이밍 입력과 시간 측정 코드가 없다
- [ ] 다른 릴레이와 비교하는 순위표가 없다
- [ ] 참여 인원 수가 보상이나 등급으로 이어지지 않는다
