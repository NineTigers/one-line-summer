# 한 줄 여름 V5 체험 점검표

대상: `prototype/`

```bash
python3 -m http.server 4184 --bind 127.0.0.1 --directory prototype
```

`http://127.0.0.1:4184/`에서 연다.

## 1. 첫 진입

- [ ] 첫 화면에서 `한 번에 한 획`, `여러 갈래`, `함께 만든 흔적`이
  보인다.
- [ ] `첫 선 그리기`와 `같은 시작, 다른 결과 먼저 보기`가 구분된다.
- [ ] 샘플 비교에서 같은 첫 선 뒤 결과가 실제로 다르다.
- [ ] 점수·승패·시간 제한·보상 문구가 없다.

## 2. 첫 선 만들기

- [ ] 여름의 빛 4종과 장면 4종이 라디오로 선택된다.
- [ ] 이름을 비우면 기본 이름을 쓴다.
- [ ] 빛나는 점 가까이에서 시작해야 선이 그려진다.
- [ ] 손가락을 떼면 한 획이 끝난다.
- [ ] 제출 전 자기 획만 다시 그릴 수 있다.
- [ ] 유효 획 전에는 `이 선 건네기`가 비활성이다.

## 3. 받은 선 잇기

- [ ] 공유 URL을 새 탭에서 열면 지금까지 선을 먼저 보여준다.
- [ ] 받은 사람의 이름 입력 뒤 다음 끝점으로 이동한다.
- [ ] 앞 선은 지워지지 않는다.
- [ ] 역할 색과 이름이 바뀌어 차례가 보인다.
- [ ] 새 획 저장 후 URL이 새 Node 상태로 바뀐다.

## 4. 같은 중간 선 분기

1. 첫 획 저장 직후 URL을 복사한다.
2. 같은 URL을 새 탭 A와 B에서 각각 연다.
3. A와 B가 서로 다른 두 번째 획을 저장한다.
4. 원본 탭의 `중간 선을 골라 새 가지 만들기`로 이동한다.
5. `1번째` 상태를 선택한다.

확인:

- [ ] 원본 화면이 `여기서 갈라진 2개 결과 비교하기`를 표시한다.
- [ ] 비교 화면 두 카드가 동일한 첫 획을 가진다.
- [ ] 두 번째 획은 서로 다르다.
- [ ] 어느 결과에도 정답·우승·등급을 표시하지 않는다.
- [ ] 다른 가지 저장이 기존 가지를 덮어쓰지 않는다.

## 5. 네 획 완성

- [ ] `상대 화면으로 이어서 체험하기`로 A/B가 교대된다.
- [ ] 두 사람이 각각 두 번 참여하면 `이 그림 완성하기`가 활성이다.
- [ ] 완성 화면에 참여자 이름과 장면 문장이 보인다.
- [ ] 선이 저장된 순서로 다시 그려진다.
- [ ] PNG 저장 버튼이 있다.
- [ ] 완성 뒤에도 중간 선으로 돌아가 새 결과를 만들 수 있다.

## 6. 접근성·모션

- [ ] 주요 버튼·텍스트 입력·라디오가 접근 가능한 이름을 가진다.
- [ ] Canvas에는 텍스트 대체 이름과 별도 상태 메시지가 있다.
- [ ] 키보드 초점이 보인다.
- [ ] 색만이 아니라 이름·순서로 역할을 구분한다.
- [ ] `?motion=reduce`에서 반복 펄스가 억제된다.
- [ ] `?motion=reduce` 완성 화면은 재생을 기다리지 않고 즉시 `완성`이다.

## 7. 레이아웃

- [ ] 390×844에서 가로 스크롤이 없다.
- [ ] 320×760에서 홈 제목·샘플·CTA가 잘리지 않는다.
- [ ] 320×760에서 그리기 Canvas와 두 버튼이 한 화면 폭 안에 있다.
- [ ] 최소 터치 영역이 44px다.
