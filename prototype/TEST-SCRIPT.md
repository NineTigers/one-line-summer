# 올여름 내가 토스할게 체험 점검표

## 확인할 가설

- 토스 입력이 상대에게 전달할 리듬으로 느껴지는가
- 상대가 만든 궤적을 받아친다는 사실이 이해되는가
- 역할을 바꾼 뒤에야 최종 결과가 나오는 이유가 납득되는가
- 결과가 반응속도 점수보다 둘의 호흡으로 느껴지는가
- 한낮·노을·여름밤의 변화가 세 공을 하나의 여름 경험으로 묶는가
- 배경이 풍부해져도 공과 입력 순간을 한눈에 찾을 수 있는가

## 플레이 순서

1. 두 사람의 이름을 입력한다.
2. 첫 사람이 한낮·노을·여름밤 세 번의 토스를 만든다.
3. 기기를 두 번째 사람에게 건넨다.
4. 두 번째 사람이 세 토스를 각각 한 번씩 스파이크한다.
5. `첫 호흡`을 확인하고 두 번째 사람이 답토스를 만든다.
6. 기기를 첫 사람에게 돌려준다.
7. 첫 사람이 답토스 세 개를 스파이크한다.
8. 최종 `오늘의 호흡`과 결과 근거를 읽는다.

## 비교 테스트

- 첫 세트에서는 공이 손에 가까이 왔을 때 토스한다.
- 답토스에서는 일부러 조금 빠르거나 느린 박자로 토스한다.
- 상대가 서로 다른 궤적을 실제로 구분해 받아치는지 확인한다.
- 한낮·노을·여름밤 전환에서 이미지가 늦게 뜨거나 깜박이지 않는지
  확인한다.
- 스파이크 순간의 화면 흔들림·빛·입자가 정타를 알아보는 데
  도움이 되는지 확인한다.
- 기기의 `동작 줄이기`를 켰을 때도 정보와 조작이 온전히 유지되는지
  확인한다.

## 테스트 후 질문

- 두 사람이 무엇을 함께한 것처럼 느껴졌나요?
- 결과가 왜 이 점수인지 이해됐나요?
- 개인 반응속도와 둘의 호흡 중 어느 쪽에 더 가까웠나요?
- 실제 지인에게 이 링크를 보내고 싶나요?
- 답토스를 보내야 최종 결과가 열린다는 구조가 번거롭나요, 궁금한가요?
- 한 사람당 세 공이 적당한가요?
- 어떤 시간대가 가장 다시 해보고 싶게 만들었나요?
- 역동적인 효과 중 줄이거나 더 키우고 싶은 것이 있나요?

## 알려진 제한

- 초대 링크가 아닌 같은 기기를 건네는 로컬 체험판이다.
- 사운드·햅틱·서버 저장·기기별 입력 지연 보정이 없다.
- 점수 공식과 결과 문구는 검증 전 가설이다.
- 새로고침하면 모든 기록이 초기화된다.
