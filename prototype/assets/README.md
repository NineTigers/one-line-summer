## V5 사용 정책

- 현재 프로토타입에서는 모든 JPG가 미사용이다.
- 정리하거나 삭제하지 않고 이전 방향의 증거로 보존한다.
- 사용자 가치와 실제 공유 게이트 전에는 V5 최종 일러스트를 만들지
  않는다.
- 향후 재사용하더라도 Canvas 선의 끝점·대비·작은 화면 가독성을
  가리는 이미지는 쓰지 않는다.
- 게임 플레이, 정타, 스파이크, 점수로 읽히는 구도는 V5 비게임
  출품 자산에 사용하지 않는다.

## V5 통과 후 후보

- 추상적인 여름 빛 텍스처
- 분기 구조가 한눈에 보이는 썸네일
- 사람 얼굴 없이도 관계와 손의 흔적을 느끼게 하는 결과 카드
- 320px·390px에서 선 대비를 유지하는 저용량 WebP
